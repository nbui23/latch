# Latch

macOS focus blocker: Electron desktop app, a privileged Swift LaunchDaemon that owns
`/etc/hosts`, and a Chromium MV3 extension bridged by a native-messaging proxy.
Local-first — no accounts, no network.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `nbui23/latch`, driven through the `gh` CLI.
See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: one `CONTEXT.md` and one `docs/adr/` at the repo root.
See `docs/agents/domain.md`.
